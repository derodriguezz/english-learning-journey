## Publish with GitHub Pages
1. Unzip the package.
2. Create a new public GitHub repository, e.g. `english-learning-journey`.
3. Upload `index.html` and the complete `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`.
7. Click **Save**.
8. After deployment, GitHub will show a public URL similar to:
   `https://YOUR-USERNAME.github.io/english-learning-journey/`
9. Open the URL in an incognito/private browser window to confirm that:
   - all three YouTube videos load;
   - brochure PDF opens;
   - audio plays;
   - mind map displays;
   - DOCX download buttons work.
